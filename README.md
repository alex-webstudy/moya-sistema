# Моя система

Личное приложение Алексея: сегодня, задачи, быстрые мысли и календарь в одном месте. Работает в браузере на телефоне и компьютере, ставится на экран «Домой» как приложение.

## Что уже есть (этап 1)

- **Сегодня**: приветствие, задачи на сегодня, мысли на разбор, ближайшие дни.
- **Задачи**: надиктуйте текст или приложите скриншоты и PDF, Claude разложит на задачи с проектом, датой и временем. Перед сохранением можно проверить.
- **Быстрая мысль**: кнопка «+» на любом экране. Вечером Claude разбирает мысли на задачи, заметки и идеи.
- **Календарь**: неделя и месяц, задачи по времени и тренировки (вт, чт, сб 19:00).
- Вход по паролю, все даты по Ташкенту.

## Запуск на своём компьютере

```bash
npm install
cp .env.example .env.local   # заполнить нужное
npm run dev
```

Без базы и без пароля приложение откроется в демо-режиме: данные лежат в памяти и сбрасываются при перезапуске. Без ключа Claude каждая строка просто становится задачей на завтра.

## Публикация

1. **Supabase** (база данных). Создайте проект на supabase.com, откройте SQL Editor и выполните файл `supabase/migrations/0001_init.sql`. В Project Settings → API возьмите `Project URL` и `service_role` ключ.
2. **Anthropic** (Claude). На console.anthropic.com создайте API-ключ.
3. **Vercel** (хостинг). Импортируйте этот репозиторий и добавьте переменные окружения:

| Переменная | Что это |
|---|---|
| `APP_PASSWORD` | пароль для входа |
| `SESSION_SECRET` | случайная строка от 32 символов |
| `SUPABASE_URL` | адрес проекта Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | серверный ключ Supabase (только на сервере) |
| `ANTHROPIC_API_KEY` | ключ Claude |

Ключи никогда не попадают в браузер: все обращения к базе и к Claude идут через сервер.
